# Android Phone Seller Website & Cloud Architecture

A production-grade, secure static web application and AWS CloudFormation architecture for an Android phone marketplace.

### Off Campus Verification
**Off Campus Code:** `GVWK7T`

---

## 🚀 Architecture & Overview
- **Frontend:** Responsive web storefront featuring modern Android smartphones, detailed technical specifications, and seamless UI/UX.
- **Cloud Infrastructure (AWS):** Production-grade AWS CloudFormation template (`cloudformation.yaml`) deploying private Amazon S3 bucket, CloudFront CDN distribution with Origin Access Control (OAC), and SSL/TLS encryption.
- **Automation:** 1-click deployment bash automation script (`deploy.sh`) for rapid provisioning and asset synchronization.
